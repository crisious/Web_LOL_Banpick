# 증거 기반 AI 코칭 대시보드 설계

- 상태: 사용자 시안 선택 및 폰트 방향 승인
- 작성일: 2026-07-11
- 선택 시안: `docs/design-assets/evidence-coaching-dashboard-reference.png`
- 적용 대상: 기존 LoL Replay Coach의 경기 상세 분석 경험과 Sites용 읽기 전용 배포판

## 목표

경기 리포트를 연 사용자가 첫 화면에서 다음 세 가지를 분리해 이해할 수 있어야 한다.

1. 실제 경기 데이터에서 관찰된 사실
2. 그 사실에 대한 AI 코치의 해석
3. 다음 경기에서 실행할 행동 루틴

## 시각 방향

- 선택된 `증거 기반 분석실` 시안을 따른다.
- 배경은 딥 네이비, 핵심 인터랙션은 시안, 사실 근거는 블루, 긍정 사건은 민트, 개선 사건은 코럴, 다음 행동은 앰버를 사용한다.
- 전체 글꼴은 `Pretendard Variable`, `Pretendard`, `Apple SD Gothic Neo`, `Noto Sans KR`, 시스템 산세리프로 통일한다.
- 점수, KDA, 시각, 퍼센트는 같은 글꼴을 유지하고 `font-variant-numeric: tabular-nums`만 적용한다.
- 별도 모노스페이스와 세리프 글꼴은 사용하지 않는다.

## 정보 구조

경기 상세의 첫 분석 영역은 다음 순서다.

1. 경기 정체성: 챔피언, 역할, 승패, 경기 시간
2. 코칭 요약: AI가 제시한 핵심 문장과 전체 요약
3. 종합 점수와 핵심 지표: 플레이 점수, KDA, 시야 점수, 킬 관여율
4. 경기 근거 타임라인: 최대 네 장면의 시간·제목·상태
5. 선택 장면 상세: `관찰된 사실`과 `AI 해석`을 별도 영역으로 표시
6. 다음 게임 프로토콜: 분석 결과의 행동 체크리스트

## 데이터 원칙

- 수치와 사건은 현재 선택된 샘플의 `normalized-match.json`과 `analysis-result.json`에서만 가져온다.
- 선택 시안의 예시 수치인 84점, 킬 관여 62%, 근거 7건은 고정 문구로 사용하지 않는다.
- 기준 샘플 `sample-kr-8254466852`에서는 83점, KDA 2/2/16, 시야 72, 킬 관여 49%, 근거 8건을 표시한다.
- 관찰된 사실에는 `relatedEventIds`로 연결된 정규화 타임라인 문장만 사용한다.
- AI 해석에는 해당 `keyMoment.description`을 사용한다.
- 근거가 없으면 명시적인 `원본 이벤트 기록 없음` 상태를 표시하고 사실을 추정하지 않는다.

## 상호작용과 접근성

- 네 장면은 네이티브 `button`으로 렌더링한다.
- 선택 상태는 `aria-pressed`로 표현하고, 키보드 포커스를 명확히 표시한다.
- 선택 시 상세 영역을 갱신하고 `aria-live="polite"`, `aria-atomic="true"`로 읽어준다.
- 행동 루틴은 네이티브 체크박스로 완료 상태를 관리하며 현재 기기에만 저장한다.
- 모바일에서는 지표, 장면, 사실·해석, 행동 루틴을 단일 열로 재배치한다.

## 기존 제품과의 경계

- 기존 로그인, 샘플 선택, Riot 조회, 다른 분석 탭과 서버 API는 유지한다.
- 새 대시보드는 기존 샘플 렌더링 단계에서 추가로 그려지며 기존 리포트 섹션을 제거하지 않는다.
- Sites 배포판은 읽기 전용이다. 루트 Node 서버를 Worker로 이식하지 않고, 빌드 시 허용된 프런트 파일과 공개 샘플 필드만 복사한다.
- 원시 Riot 응답, PUUID, Riot ID, 원본 matchId, 환경변수, 로컬 경로는 배포 산출물에 포함하지 않는다.

## 검증 기준

- 데이터 기반 지표와 네 장면 선택 동작을 자동 테스트한다.
- 관찰 사실과 AI 해석의 분리, HTML 이스케이프, 근거 없음 상태를 자동 테스트한다.
- 폰트 통일, 반응형 훅, 포커스, ARIA 계약을 소스 계약 테스트로 검증한다.
- 기존 전체 테스트와 Sites 읽기 전용 smoke 테스트가 모두 통과해야 게시한다.
